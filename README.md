## 功                                                                                              
                                                                                                                                            
  - 批量扫描指定目录                                                                                                                          
  - 检测每张图片的尺寸、格式                                                                                                                                                                                                                                          
  - 识别损坏图片和非图片文件                                                                                                                                                                                                                                          
  - 生成文本报告(屏幕打印 + 保存为 report.txt)                                                                                                                                                                                                                        
  - 完整的 pytest 自动化测试                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                      
  ## 环境要求                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                      
  - Python 3.12                                                                                                                                                                                                                                                       
  - Pillow                                                                                                                                                                                                                                                                                                                                                                     
  安装依赖:                                                                                                                                                                                                                                                                                                                                                                          
      pip install pillow pytest                                                                                                                                                                                                                                                                                                                                                               
  ## 使用方法                                                                                                                                                                                                                                                                                                                                                                         
  1. 生成测试图片(可选,用于演示):                                                                                                                                                                                                                                                                                                                                                                         
          python make_test_images.py                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                      
  2. 运行检查工具:                                                                                                                                                                                                                                                       
          python image_checker.py                                                                                                                                                                                                                                                                                                                                                            
     会打印报告到屏幕,并生成 report.txt。                                                                                                                                                                                                                                                   
  ## 运行测试                                                                                                                                                                                                                                                            
      pytest -v
